Rutina lista

Descarga los dos archivos y súbelos a GitHub dentro de la carpeta

  1. Entra a tu repositorio en github.com y abre la carpeta rutinas.
  2. Pulsa Add file → Upload files.
  3. Arrastra los dos archivos. En el campo de la ruta escribe antes del nombre, o crea primero la carpeta.
  4. Pulsa Commit changes. En menos de un minuto el link ya funciona.

Para editar esta rutina después: vuelve aquí, pulsa «Importar JSON», elige el rutina.json que descargaste, haz los cambios y sube los archivos otra vez a la misma carpeta. El link no cambia.
